# BANKING SYSTEM

A backend Banking Management System built using **Java and Spring Boot**.  
This project provides core banking functionalities such as user management,
secure authentication, account handling, and transaction processing.

---

##  Project Type
Backend Application (REST API)

---

##  Domain
Banking System

---

## 🛠 Tech Stack
- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate / JPA
- MySQL
- Maven
- RESTful APIs

---

## ✨ Features
- User registration and login
- JWT-based authentication & authorization
- Role-based access control (Admin / User)
- Account creation and management
- Money transfer between accounts
- View transaction history
- Secure password encryption
- Global exception handling

---

## 🔐 Authentication
- JWT (JSON Web Token)
- Spring Security

---

## 🗄 Database
- MySQL
- Hibernate ORM (JPA)
